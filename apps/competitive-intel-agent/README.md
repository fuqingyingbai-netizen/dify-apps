# 竞品情报自动分析助手（Agent 对话）

用 Agent 模式搭建的竞品情报助手：围绕指定竞品，自动拆解分析任务、调用工具收集信息，最后输出结构化的情报分析。

## 应用信息

- 应用类型：Agent 对话（Agent Chat）
- 应用模式：`agent-chat`
- 默认模型：`gpt-4o-mini`（OpenAI）
- 依赖插件：无
- Agent 配置：开启 Agent 模式，最大迭代 10 轮

## 能力说明

- 支持多轮对话，围绕竞品持续追问与细化
- 开启工具调用，可在 Dify 中挂载搜索、抓取、代码执行等工具
- 提示词可在 Dify 中打开应用 → 编排 → 提示词里查看与修改

## 使用前提

1. 在工作区配置 **OpenAI API Key**（或在编排里把模型换成你已有的供应商）
2. 根据分析目标，在 Agent 里挂载需要的工具（如联网搜索）

## 导入方法

在 Dify 工作室点击 **创建应用 → 导入 DSL 文件**，选择本目录的 `app.yml`。

> 提示：这个应用体积小、结构简单，适合作为自己搭建 Agent 应用的起点，把提示词和工具替换成你的场景即可。
