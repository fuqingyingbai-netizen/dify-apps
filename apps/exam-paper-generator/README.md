# 出题组卷（工作流）

把教学文档交给工作流，自动生成一份试卷（选择题、填空题、简答题），并把结果写回飞书文档。

## 应用信息

- 应用类型：工作流（Workflow）
- 应用模式：`workflow`
- 依赖插件：
  - `langgenius/deepseek` —— 提供 DeepSeek 模型，用于生成试卷内容
  - `langgenius/feishu_document` —— 读写飞书云文档

## 工作流结构（13 个节点）

| 顺序 | 节点 | 类型 | 作用 |
| --- | --- | --- | --- |
| 1 | 用户输入 | start | 接收文档与出题要求 |
| 2 | 文档提取器 | document-extractor | 从上传的文档中提取文字 |
| 3 | 生成试卷名称 | llm | 根据文档内容生成试卷标题 |
| 4 | 模板转换 | template-transform | 拼接后续提示词上下文 |
| 5 | 提取飞书标识符 | llm | 从飞书链接中解析文档标识 |
| 6 | 生成选择题 | llm | 生成选择题部分 |
| 7 | 生成填空题 | llm | 生成填空题部分 |
| 8 | 生成简答题 | llm | 生成简答题部分 |
| 9-11 | 在飞书文档中新增内容（三个节点） | tool | 把各部分内容依次写入飞书文档 |
| 12 | 获取飞书云文档的内容 | tool | 读取写入结果用于输出 |
| 13 | 输出 | end | 返回最终结果 |

## 使用前提

1. 在工作区安装并配置 **DeepSeek 插件**（填写自己的 API Key）
2. 安装 **飞书文档插件**，并配置飞书应用的 App ID / App Secret，同时把目标文档授权给该应用
3. 准备一个用于写入试卷的飞书文档，运行工作流时填入文档链接或文件夹 token

## 导入方法

在 Dify 工作室点击 **创建应用 → 导入 DSL 文件**，选择本目录的 `app.yml` 即可。

> 说明：DSL 不包含密钥与飞书凭证，导入后需要按上面的步骤补齐配置。
