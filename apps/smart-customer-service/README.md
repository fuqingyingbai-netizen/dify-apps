# 智能客服（高级对话）

面向客服场景的对话应用：先把用户问题分类，再走对应分支，其中知识问答分支会先检索知识库，再交给大模型组织回答。

## 应用信息

- 应用类型：高级对话（Advanced Chat）
- 应用模式：`advanced-chat`
- 依赖插件：
  - `langgenius/deepseek` —— 提供 DeepSeek 模型
  - `ki3dn/rankgpt` —— 第三方排序/召回增强插件（可选，不需要时可移除相关节点）

## 编排结构（8 个节点）

| 顺序 | 节点 | 类型 | 作用 |
| --- | --- | --- | --- |
| 1 | 用户输入 | start | 接收用户消息 |
| 2 | 问题分类器 | question-classifier | 判断问题类型，分流到不同处理分支 |
| 3 | 代码执行 | code | 对输入做预处理 |
| 4 | LLM | llm | 直接回答类分支 |
| 5 | 代码执行 2 | code | 检索结果预处理 |
| 6 | 知识检索 | knowledge-retrieval | 从知识库召回相关内容 |
| 7 | LLM 2 | llm | 基于检索结果生成回答 |
| 8 | 直接回复 | answer | 返回最终回复 |

## 使用前提

1. 安装并配置 **DeepSeek 插件**（填写 API Key）
2. 如需排序增强，安装 **ranKGpt 插件**；不需要时可以删除相关节点
3. **绑定自己的知识库**：知识库内容不会随 DSL 导出，导入后需要在「知识检索」节点里重新选择数据集

## 导入方法

在 Dify 工作室点击 **创建应用 → 导入 DSL 文件**，选择本目录的 `app.yml`。

> 说明：导入后请先检查知识库绑定与模型配置，否则知识问答分支无法正常工作。
